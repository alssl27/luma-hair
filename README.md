# Luma House Salon Website

A polished, responsive concept website for a modern luxury hair salon. The project combines editorial visual design with practical front-end features, including appointment booking and a JavaScript-powered hairstyle recommendation tool.

## Features

- Responsive single-page layout for mobile, tablet and desktop
- Sticky navigation, mobile menu, smooth scrolling and active section states
- Service menu with direct booking actions
- Appointment form with validation and a saved booking summary
- Browser `localStorage` persistence with edit and cancel controls
- AI-style hairstyle matcher using stylist-inspired JavaScript rules
- Gallery, testimonials, contact form and opening hours
- Scroll reveals, hover states and a back-to-top control
- Semantic HTML, labelled form controls and keyboard-friendly interactions

## Technologies

- HTML5
- CSS3 with custom properties, Grid, Flexbox and media queries
- Vanilla JavaScript
- Browser Local Storage API
- Intersection Observer API

## Run The Project

Open `index.html` directly in a browser, or serve the folder with a local development server:

```bash
npx serve .
```

Then open the local URL shown in the terminal.
